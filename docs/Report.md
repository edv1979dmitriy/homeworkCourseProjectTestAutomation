## Отчёт по итогам тестирования

### Краткое описание

Произведено тестирование позитивных и негативных сценариев покупки тура в приложении *aqa-shop* при покупке как по карте (через сервис Payment Gate), так и в кредит (через сервис Credit Gate). Также проведены API-тесты. Отчёт сформирован в системе репортинга Allure.

### Статистика

1. Всего тестов: 56.
2. Успешных тестов: 28.
3. Проваленных тестов: 28.
4. Процент успешного прохождения тестов: 50%.

### Рекомендации

1. Устранить критическую уязвимость API, позволяющая осуществлять доступ к сервисам только по номеру, без ввода других данных карты.
2. Добавить сообщения об ошибках при превышении допустимого количества символов, вводе недопустимых значений при заполненнии полей карты.
