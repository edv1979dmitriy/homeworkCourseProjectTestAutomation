# Тестовый план

## Объект:

Приложение aqa-shop.

## Цель

Автоматизация тестирования сценариев покупки тура.

### Перечень автоматизируемых сценариев:

Общие указания:
   - для всех тестов должно быть настроено формирование отчетов с помощью фреймворка "Allure";
   - после каждого теста БД должна полностью очищатся.

1. Обычная оплата по дебетовой карте - позитивный сценарий:
   - нажать кнопку "Купить". Ожидаемый результат - появилась форма *Оплата по карте*;
   - заполнить поля валидными данными:
     - "Номер карты" - *1111 2222 3333 4444*;
     - "Месяц" - любое число от 01 до 12, например *05*;
     - "Год" - последние две цифры года (от текущего до не позже текущий год + 5), например *27*;
     - "Владелец" - только буквы (латиница, регистр не важен), пробелы, дефисы, не более 26 символов, например *Andrey Petrov*;
     - "CVC/CVV" - только три цифры, например *123*;
   - нажать кнопку "Продолжить". Ожидаемый результат - появилось всплывающее окно с уведомлением *Успешно* + *Операция одобрена Банком.*; 
2. Выдача кредита по данным банковской карты - позитивный сценарий:
   - нажать кнопку "Купить в кредит". Ожидаемый результат - появилась форма *Кредит по данным карты*;
   - заполнить поле "Номер карты" - *5555 6666 7777 8888*;
   - заполнить остальные поля валидными данными (см. пункт 1);
   - нажать кнопку "Продолжить". Ожидаемый результат - появилось всплывающее окно с уведомлением *Успешно* + *Операция одобрена Банком.*;
