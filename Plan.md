# Тестовый план

## Объект:

Приложение aqa-shop.

## Цель

Автоматизация тестирования сценариев покупки тура.

### Перечень автоматизируемых сценариев:

Общие указания:
   - для всех тестов должно быть настроено формирование отчетов с помощью фреймворка "Allure";
   - после каждого теста БД должна полностью очищатся;
   - валидные данные:
     - "Номер карты" "APPROVED" - *1111 2222 3333 4444*;
     - "Номер карты" "DECLINED" - *5555 6666 7777 8888*;
     - "Месяц" - любое число от 01 до 12, например *05*;
     - "Год" - последние две цифры года (от текущего до не позже текущий год + 5, с учётом введённого значения "Месяц" - дата не должна быть прошедшей), например *27*;
     - "Владелец" - только буквы (латиница, регистр не важен), пробелы, дефисы, не более 26 символов, например *Andrey Petrov*;
     - "CVC/CVV" - только три цифры, например *123*;

1. Обычная оплата по дебетовой карте - позитивный сценарий:
   
   1.1 С карты *APPROVED* через сервис *Payment Gate*:
      - нажать кнопку "Купить". Ожидаемый результат - появилась форма *Оплата по карте*;
      - заполнить поля валидными данными (карта *APPROVED*);
      - нажать кнопку "Продолжить". Ожидаемый результат - появилось всплывающее окно с уведомлением *Успешно* + *Операция одобрена Банком.*;
      - получить из БД значение столбца status - последнее по времени записи (по полю created) в таблице payment_entity. Ожидаемый результат: *APPROVED*;
      - получить из БД значение столбца payment_id - последнее по времени записи (по полю created) в таблице order_entity. Ожидаемый результат: поле заполнено (значение не *NULL*).

   1.2 С карты *DECLINED* через сервис *Payment Gate*:
      - нажать кнопку "Купить". Ожидаемый результат - появилась форма *Оплата по карте*;
      - заполнить поля валидными данными (карта *DECLINED*);
      - нажать кнопку "Продолжить". Ожидаемый результат - появилось всплывающее окно с уведомлением *Успешно* + *Операция одобрена Банком.*;
      - получить из БД значение столбца status - последняя по времени записи (по полю created) в таблице payment_entity. Ожидаемый результат: *DECLINED*;
      - получить из БД значение столбца payment_id - последняя по времени записи (по полю created) в таблице order_entity. Ожидаемый результат: поле заполнено (значение не *NULL*).
